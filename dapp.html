Multi-Chain Wallet Signing Test

QA tool for wallet parse-transaction / signing UI. Four test suites in the sidebar: Simulation Failures (5 chains), EVM Interactions (ERC20/721/1155/EIP-747), EVM Message Signing (eth_sign / personal_sign / typed data / permit), and Solana Authority Changes (legacy, targets parse-transaction's authorityChanges).
Testnet by default. Toolbar switches between testnet and mainnet. EVM cases use eth_sendTransaction (the standard browser-wallet entrypoint) — the wallet runs its simulation before the prompt appears. Just cancel in the wallet prompt after inspecting the simulation error. Solana / TRON cases use pure sign-only APIs. On the Authority Changes page, "Sign & Send" is a real broadcast — prefer "Sign only".

Solana Authority Changes

Original PR 773 test scenarios. Triggers Binance Wallet's parse-transaction API to inspect the authorityChanges field for SPL Token SetAuthority and System Assign.

SetAuthority · AccountOwner
SetAuthority · CloseAccount
System Assign
PR 773 expects type=token_account_owner. Signer must currently own the token account.
PR 773 expects type=token_close. Changes the CloseAccount authority.
⚠️ Irreversible on mainnet. SystemProgram.assign transfers the connected wallet account's owner program away from System Program. After broadcast, that wallet can no longer sign via System Program and will lose its SOL. Strongly prefer Sign only.
PR 773 expects type=account_owner. The signer is the account being reassigned.

Add Custom Chain
